# ImagePastor 1.2.0

- Adds the opt-in tray setting **Auto Sleep After 15 Min Away**.
- Requires a full 15 minutes of fresh no-face camera evidence AND no keyboard/mouse activity before enabling the existing monitor sleep guard.
- Face detection or input activity restarts the timer. Camera errors, stale observations, and unavailable idle state never count as absence.
- Preserves Ctrl+Alt+Shift+M for manual sleep/wake. Manual wake, unlock, and app restart begin a fresh observation period.
- Pauses camera monitoring on session lock and secure desktop. Face wake and away detection share a serialized camera helper; no simultaneous camera owners.
- Keeps Wake on Face independent. After auto-sleep verifies departure, sustained face return can wake immediately when face wake is enabled.
- Exchanges only temporary current presence metadata between processes, not frames or face templates. No keyboard/mouse contents or activity history is collected.

The new option defaults off, including in the installer. It uses the camera while
the PC is awake when enabled. Existing configuration and camera selection are
preserved on upgrade. Turn the option on in the tray after installation.

Windows 10/11 x64; Python is bundled. Browser extension setup remains manual.
Quit ImagePastor and its diagnostic companion before upgrading. The installer
is unsigned; verify the included SHA-256 checksum and keep Windows protections enabled.

Verification uses deterministic timing and mocked camera/session lifecycle tests,
the complete Python suite, browser/chime tests, compilation, clean packaging, and
installer checksum verification. A real 15-minute camera-absence session was not
performed during development; camera/lighting behavior remains device-dependent.

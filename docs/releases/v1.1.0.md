# ImagePastor 1.1.0

Windows 10/11 x64 installer. Python is bundled; no developer tools are required.

- Per-user installation, Start menu shortcut, optional desktop shortcut and Windows startup.
- Vivaldi tile-aware capture and verified ChatGPT paste targeting, without tab scanning or voice-button fallback clicks.
- Monitor sleep guard, opt-in local face wake, and bounded abnormal-exit recovery.
- Optional independently running lifecycle diagnostics with process exit and Windows hang evidence.
- Bundled ChatGPT completion-chime extension and Codex notifier assets; browser setup remains manual.
- Privacy-safe, fail-closed LPHA workflow; personal provider macro disabled on fresh installs. Remote Citrix forms without semantic accessibility remain unsupported.

Fresh installation does not include the developer's settings, camera selection,
logs, captures, browser sessions, or saved paste target. Camera wake and screenshot
saving default off. Settings are preserved across upgrades.

After installation, point inside the destination ChatGPT tile and press
Ctrl+Alt+Shift+V. Ctrl+Alt+V captures the source window/page under the pointer.
Ctrl+Alt+Shift+M toggles the monitor sleep guard. Face detection, when enabled,
can disable that guard. Recovery after an abnormal exit starts with the guard off.

Quit the app and diagnostic companion before upgrading or uninstalling.
The installer is unsigned; SHA-256 checksums are supplied. Keep Windows security
protections enabled. This private release requires repository access to download.

Verification: full Python regression suite, browser/chime tests, clean payload
privacy checks, installer compilation and checksum verification. No live Citrix
form entry or installation on another person's computer was performed.
